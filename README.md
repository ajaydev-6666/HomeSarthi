# HomeSarthi User & Admin Panel (Frontend Demo)

## Folder structure
- `user.html` — customer dashboard and loan enquiry form
- `admin.html` — admin dashboard, application review and status updates
- `css/style.css` — shared responsive styling
- `js/app.js` — demo application storage and panel interactions

## Run
1. Keep the folder structure unchanged.
2. Open `user.html` in a browser (or use VS Code Live Server).
3. Submit a sample loan enquiry.
4. Open `admin.html` in the same browser to see it and update its status.

## Important
This is a frontend-only prototype. Data is stored in the browser's localStorage, not a server/database. The admin page has no real authentication and must not be used to manage real customer data. Before launch, connect a backend (for example Spring Boot + MySQL), implement secure login/role permissions, server-side validation, and appropriate privacy/security controls.
